# results/paper: analysis outputs

Generated by `julia --project=analysis src/analysis/run_analysis.jl` from `pilot_merged` (600 runs). Do not edit by hand.

All CSVs are plain comma-separated with a header row, ready for `\addplot table[col sep=comma]` (pgfplots). PNGs are previews only.

## Mapping to the manuscript

* `profile_main_*.csv, profile_main_*.png`: **Fig. 3 and its discussion** (replaced): performance profiles of the main set (OURS, ARM, WATCH, SPEC, ADATR, ASTR1, LIPAPP) on #F, #∇F, weighted cost and wall time, one per tolerance.
* `profile_all_*.csv, profile_all_*.png`: Appendix version of the profiles: all 12 methods.
* `reliability_<ε>_<metric>.csv, reliability.png`: **Reliability and performance tables**: one row per method (best configuration), per tolerance, Appendix-D columns, metric averaged over reliable runs.
* `events_<ε>.csv, events_1e-3.png`: **Table 4 (triggering events)**: OURS event proportions and rejection rate.
* `algorithms_table.csv, all_algorithms_reliability.csv`: **Supplement algorithm table** (the 100 algorithms).
* `best_configurations.csv, profile_summary.csv, success_summary.csv`: supporting numbers (which configuration is 'best', ρ(1) and ρ(∞), mean/median costs of reliable runs).

## Conventions

* **Reliable at ε**: the method hit ε and F(x_hit) < F(x_0) (the paper's definition, per tolerance).
* **Best configuration** of a method at ε: highest reliability at ε over its hyperparameter grid; ties are broken by the smaller median #∇F of the reliable runs.
* **Performance profiles** (Dolan–Moré): cost of a solver on a problem-start pair is its metric at the first hit of ε if the run is reliable, else ∞. ρ_s(τ) is the fraction of pairs with ratio to the best solver ≤ τ. Pairs that no solver of the set solves are dropped (`n_pairs_dropped` in `profile_summary.csv`). For #F the metric is #F + 1 (gradient-only methods have #F = 0).
* **Weighted cost** = #F·c + #∇F with c = (mean time per F)/(mean time per ∇F) computed per run from that run's timings (c = 0 for methods without F evaluations).
* **Margins** are 95% normal-approximation margins 1.96·sd/√n (0 when n < 2). In the Appendix-D tables `total.x` = problem-start pairs, `total.y` = reliable runs.
* **Events** are percentages of inner loops, computed per run up to the outer iteration of the first ε hit and averaged over runs; flags are not mutually exclusive.
